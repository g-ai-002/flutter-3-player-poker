# 斗地主 🃏

经典三人斗地主单机游戏，基于 Flutter + Flame 开发，支持 Android、Windows 与 Web 三平台。
完全本地运行，不包含任何联网功能。

## 功能

- 🎴 标准 54 张牌：三人各 17 张，3 张底牌，地主确定后归地主所有
- 🏷️ 完整牌型：单张、对子、三张、三带一/二、顺子、连对、飞机（带单/带对）、四带二、炸弹、王炸
- ⚖️ 严格的大小比较：同牌型同长度比点数，炸弹压普通牌，王炸最大
- 🎯 叫分抢地主：依次叫 1 / 2 / 3 分，最高分成为地主，叫分即底分
- ✖️ 加倍：地主先选，两名农民随后，每次加倍倍数 ×2
- 👁️ 明牌：地主可在加倍回合亮出手牌，本局倍数再 ×2；高手 AI 会择机明牌
- 🤖 三档 AI 难度：入门保守、标准会记牌并保留控制牌、高手额外按最少手数拆牌
- 🧠 AI 决策：跟牌最小压制、农民不压队友、领出不拆炸弹与王炸、局势宽松时保留 2 与王、
  炸弹用于一手收尾、对手只剩一张时改领大牌
- 🛟 异常兜底：AI 叫分 / 加倍 / 出牌被拒绝时自动降级，对局不会卡死
- 💡 提示：自动选出能压过上家的最小牌型，优先不拆炸弹/王炸，也可在领出时给出建议
- 🔍 记牌器：顶栏一键在牌桌上方常驻浮层，无遮罩不打断操作，实时查看两家剩余的牌，
  地主明牌后自动扣除已知手牌，点浮层关闭按钮收起
- ✋ 连续选牌：手牌支持横向拖动一次选中或取消一片，单击切换选中保持不变
- ⏱️ 出牌倒计时：每回合 20 秒，超时自动不出；领出超时自动打出最小单张
- 🔊 程序化声音：发牌、出牌、炸弹、加倍与结算音效全部实时合成，另有 12 秒循环背景音乐，
  启动即预热、失败自动重试并写入日志，设置页可分别关闭或试听
- 🔁 不出 / 两家不出后重新领出 / 自动轮转
- 💥 炸弹与王炸翻倍，春天 / 反春天再翻倍
- 🧮 结算：地主与农民分别计分，展示三家本局得分与倍数
- 📜 牌谱：逐手记录叫分、明牌、加倍与出牌，保留最近 20 局，可复制或导出文本
- 🎞️ 复盘：从牌谱逐手回看三家剩余手牌、当前动作与本步倍数，旧牌谱降级为动作回放
- 📊 生涯统计：局数、胜率、累计积分、地主/农民胜率、最高连胜
- 🌓 深色 / 浅色主题，牌桌固定深色绒面
- 🐢 三档 AI 速度：快速 / 标准 / 从容
- ⚙️ 逻辑更新速率：30Hz / 60Hz / 120Hz 三档，默认 60Hz；逻辑与渲染解耦，低配省电、高刷更顺滑
- 📝 日志：按天落盘到用户目录，设置页可查看、复制与打开目录，未捕获异常自动记录
- 🪑 三足鼎立牌桌：左右两家出牌区在牌桌两侧偏上、玩家出牌区贴底居中，牌面随窗口宽度放大，
  出牌飞行动画按实际出牌区落地
- 🖥️ 满屏牌桌：顶栏、底牌、倍数与操作按钮全部悬浮在四周，牌桌拿满整屏剩余空间；
  提示信息固定槽位悬浮显示，出现或消失都不会让牌桌与手牌移位
- 📱 响应式布局：主页在手机上单列、宽屏双栏、手机横屏与小窗口左右并排；牌桌牌面随屏幕放大，
  竖屏提示落在座位行中间不压牌面，悬浮层避开横屏刘海与挖孔；手机自动全屏横屏，
  折叠屏、平板与桌面窗口自适应，内容页在大屏限制最大行宽
- 🌐 简体中文界面，Windows 优先使用 Microsoft YaHei UI

### v0.5.5

性能与流畅度版本：牌桌逻辑更新速率开放为 30Hz / 60Hz / 120Hz 三档，默认 60Hz。
逻辑更新与渲染帧率解耦，由固定步长时钟把每帧的可变时间累积成固定逻辑步：30Hz 减半逻辑开销更省电，
120Hz 适合高刷屏更顺滑；掉帧后最多补 4 步并丢弃追不上的时间，避免连续补帧把界面拖得更卡。
设置页可随时切换，进入牌桌后生效，对局日志会记录当前速率。

### v0.5.4

多设备显示优化版本：主页按窗口宽高自动切换单列 / 双栏 / 左右并排，桌面不再把内容挤在 520 逻辑像素的
中间条里，手机横屏与小窗口也无需滚动就能点到「开始对局」，宽屏下牌扇、标题与统计同步放大；
出牌区牌面随牌桌宽度线性放大到 96 像素封顶，4K 与超宽屏不再显示小牌；手牌拥挤时按每张至少露出
36% 牌宽压缩，窄屏 20 张手牌的 10 / J / Q 角标不再被盖住；悬浮顶栏、提示层、记牌器与浮层面板
统一避开横屏刘海与挖孔，浮层宽度按实际可用空间收敛。

### v0.5.3

显示空间优化版本：牌桌拿满整屏剩余空间，顶栏、底牌、倍数与操作按钮改为悬浮层，
底牌内嵌顶栏胶囊后省下整条底牌带，小屏横屏下牌桌高度从 138 提升到 194 逻辑像素（约 +40%）；
轮次、上一手、明牌提醒与临时反馈统一到牌桌上方悬浮提示层，每行固定高度且不拦截点击，
提示出现或消失不会推动牌桌、手牌与按钮，叫分 / 加倍 / 出牌阶段切换也保持同一套几何；
竖屏时提示层自动避开左右座位，打开记牌器时暂停提示层避免文字叠加。

### v0.5.2

体验修复版本：牌桌改为三足鼎立布局，左右两家出牌区占据牌桌上两侧、玩家出牌区贴底居中，

AI 标准与高手都会记牌，局势宽松时保留 2 与王，炸弹用于一手收尾，对手只剩一张时改领大牌。
修复出牌听不到音效的问题：背景音乐与音效曾各自初始化 SoLoud，第二次 init 会重建引擎并中断音源加载，

### v0.5.1

## 开发

### 环境要求

- Flutter 3.47.9+（Dart 3.13.7+）
- Android SDK 37（minSdk 35 / targetSdk 37 / compileSdk 37）
- Windows 10+

### 运行

```bash
flutter pub get
flutter run
```

### 测试

```bash
flutter analyze
flutter test
```

### 构建

构建统一由 CI 完成（在 Actions 里手动触发，选中 `v*` tag 运行即按该 tag 发布），本地不要求配置完整构建链。

## 目录

```text
lib/
├── game/          牌型识别、对局引擎、AI、记牌器、回合调度、动作广播、牌谱记录、Flame 牌桌
├── models/        扑克牌、设置与牌谱模型
├── pages/         主页、牌桌、玩法、统计、牌谱、设置
│   └── game/      牌桌布局、操作区、顶栏与浮层
├── providers/     对局状态与设置状态
├── services/      日志、音频合成、存储、统计、牌谱、文件系统
├── theme/         明暗主题与按钮样式
├── utils/         常量、格式化、窗口与平台工具
└── widgets/       手牌、牌面、座位、出牌区、记牌器、浮层外壳与通用卡片
```

## 日志与导出位置

- Windows：`文档/FlutterDdz/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterDdz/logs/`
- Web：仅保留在内存，可在设置页查看
- 牌谱文本（`ddz_hand_*.txt`）：同目录下的 `exports/`，Web 端请使用复制到剪贴板

日志单文件超过 5MB 自动轮转，保留 7 天。

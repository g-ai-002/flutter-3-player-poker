# 斗地主 🃏

经典三人斗地主单机游戏，基于 Flutter + Flame 开发，支持 Android、Windows 与 Web 三平台。
完全本地运行，不包含任何联网功能。

## 功能

- 🎴 标准 54 张牌：三人各 17 张，3 张底牌，地主确定后归地主所有
- 🏷️ 完整牌型：单张、对子、三张、三带一/二、顺子、连对、飞机（带单/带对）、四带二、炸弹、王炸
- ⚖️ 严格的大小比较：同牌型同长度比点数，炸弹压普通牌，王炸最大
- 🎯 叫分抢地主：依次叫 1 / 2 / 3 分，最高分成为地主，叫分即底分
- ✖️ 加倍：地主先选，两名农民随后，每次加倍倍数 ×2
- 👁️ 明牌：地主可在加倍回合亮出手牌，本局倍数再 ×2；高手 AI 会择机明牌
- 🤖 三档 AI 难度：入门保守、标准会记牌并保留控制牌、高手额外按最少手数拆牌
- 🧠 AI 决策：跟牌最小压制、农民不压队友、领出不拆炸弹与王炸、局势宽松时保留 2 与王、
  炸弹用于一手收尾、对手只剩一张时改领大牌
- 🛟 异常兜底：AI 叫分 / 加倍 / 出牌被拒绝时自动降级，对局不会卡死
- 💡 提示：自动选出能压过上家的最小牌型，优先不拆炸弹/王炸，也可在领出时给出建议
- 🧑‍🏫 牌局教练：提示附带一句理由（最小压制、不拆炸弹、一手走完、剩余手数），
  叫分时显示手牌牌力与建议叫分，对手只剩 1~2 张时在牌桌上方提醒残局打法
- 🔍 记牌器：顶栏一键在牌桌上方常驻浮层，无遮罩不打断操作，实时查看两家剩余的牌，
  地主明牌后自动扣除已知手牌，点浮层关闭按钮收起
- ✋ 连续选牌：手牌支持横向拖动一次选中或取消一片，单击切换选中保持不变
- ⏱️ 出牌倒计时：每回合 20 秒，超时自动不出；领出超时自动打出最小单张
- 🔊 程序化声音：发牌、出牌、炸弹、加倍与结算音效全部实时合成，另有 12 秒循环背景音乐，
  启动即预热、失败自动重试并写入日志，设置页可分别关闭或试听
- 🔁 不出 / 两家不出后重新领出 / 自动轮转
- 💥 炸弹与王炸翻倍，春天 / 反春天再翻倍
- 🧮 结算：地主与农民分别计分，展示三家本局得分与倍数
- 📜 牌谱：逐手记录叫分、明牌、加倍与出牌，保留最近 20 局，可复制或导出文本，
  详情页逐手展示三家牌面、动作与本步倍数
- 📊 生涯统计：局数、胜率、累计积分、地主/农民胜率、最高连胜
- 🌓 深色 / 浅色主题，牌桌固定深色绒面
- 🐢 三档 AI 速度：快速 / 标准 / 从容
- ⚙️ 逻辑更新速率：30Hz / 60Hz / 120Hz 三档，默认 60Hz；逻辑与渲染解耦，低配省电、高刷更顺滑
- ⚡ 流畅度：点牌只刷新手牌、操作条与提示层；牌面与浮尘预渲染，出牌动画不再每帧重排文字；
  背景音乐在后台 isolate 合成，首次进桌也不掉帧
- 🎯 牌面清晰：白底 + 纯正红黑两色（对比度达 WCAG AA），牌点、花色与镜像点数不叠透明度，
  顶栏底牌放大到 34×47.6、牌点一眼看清；飞牌与牌桌牌面共用同一套配色，动画落定无色差
- 📝 日志：按天落盘到用户目录，设置页可查看、复制与打开目录，未捕获异常自动记录
- 🪑 中央牌桌：三家出牌区聚在牌桌正中间，左右两家分别朝自家座位倾斜，玩家出牌区居中贴底，
  方便一眼比较三家的上一手；横屏两家头像各自贴边、相对牌桌中线对称；牌面随窗口宽度放大，
  出牌动画从各家头像（玩家为手牌）起飞，张数、尺寸与落点都与牌桌出牌区一致，
  出过的牌等动画落定后才亮出
- 🖥️ 居中网格：牌桌网格始终居中，顶栏、底牌、提示与操作按钮全部悬浮在网格四周；
  轮次与上一手等牌局进度信息居中显示在网格正上方，宽屏时残局提醒与临时反馈再分列左右，
  窄屏四条提示槽位叠在网格上方，出现或消失都不会让牌桌与手牌移位
- 📱 响应式布局：主页在手机上单列、宽屏双栏、手机横屏与小窗口左右并排；牌桌牌面随屏幕放大，
  竖屏提示落在预留的提示带内不压牌面，悬浮层避开横屏刘海与挖孔；
  手机按网格比例决定方向——横屏能把网格放得明显更大才自动横屏全屏（如 390 / 412 宽的长屏手机），
  360 宽的手机与矮屏手机保持竖屏，平板与折叠屏沿用系统方向
- 🧹 干净退出：离开牌桌即取消 AI 与提示定时器、停止背景音乐、退订事件并停止渲染循环，不残留后台任务
- 🌐 简体中文界面，Windows 优先使用 Microsoft YaHei UI

### v0.6.6

牌桌对称与底牌显示修复版本（issue #7）：横屏时右侧座位此前被缩放盒推到自己的左边缘，两家头像到屏幕两侧的
留白一大一小，左家看着离牌桌更远；现在右侧座位按右上对齐，两家头像相对牌桌中线完全对称。顶栏中央的底牌
从小牌点放大到 34×47.6，顶栏同步加高到 52，「底牌」标签与牌背描边一并提亮，明牌前后都能一眼看清几张牌。
底牌变高后横屏网格反而更小，360 宽的长屏手机改为保持竖屏（竖屏网格更宽），390 / 412 宽的手机继续自动横屏。

### v0.6.5

飞牌与提示修复版本（issue #6）：出牌飞行动画的起点不再是估算的座位坐标，而是各家座位上的头像——
牌桌页把两家 AI 头像与人类玩家手牌上沿的位置一帧回传给 Flame 层，飞牌从头像起飞、落到出牌区，
横屏紧凑座位与大屏下也不会飘在空中；发牌动画同样从手牌出发。宽屏下的牌局进度信息（轮次胶囊 +
上一手 / 阶段提示）统一居中摆在网格正上方，残局提醒与临时反馈仍分列左右，横屏提示带同步加高，
居中文字不会压到牌堆。顺手清掉从未被读取的 `showCombo` 与 `trickSerial`，代码量 9,992 行。

### v0.6.4

牌面清晰度修复版本（issue #5）：修掉 0.6.3 性能优化遗留的一层 `Opacity(0.45)`——此前整张牌面被当成半透明
内容绘制，牌点与花色只有 45% 不透明度，白底上叠出来就是一片灰。现在牌点恢复纯正红黑两色，牌底更白、
描边更实，中心花色与右下角镜像点数也不再压透明度，小尺寸底牌同样清楚；牌桌飞牌与 Flutter 牌面共用同一组
配色常量，动画落定前后不会出现色差。新增牌面配色测试守住对比度（红黑两色均达 WCAG AA），代码量 9,930 行。

### v0.6.3

性能与流畅度版本：选牌不再重建整张牌桌页，点选一张牌只刷新手牌、操作条与提示层；每张手牌独立重绘，
选一张只重画它自己。牌桌层把牌面预渲染成图片缓存，飞牌动画每帧不再重新排版点数与花色文字；
炸弹冲击波复用画刷，浮尘直接烘进绒面底图，每帧 22 次圆形绘制降为 0。出牌区几何同帧合并并按值去重，
选牌、快门等无关重建不会再写回牌桌层。12 秒背景音乐改用后台 isolate 合成，第一次进桌的发牌动画也不再卡顿。
代码量 9,934 行。

### v0.6.2

出牌动画修复版本（issue #4）：出牌的飞行动画不再固定 34×48 的小牌，落定时刚好放大到牌桌上牌面的实际大小，
横屏、平板与高分屏都跟着牌桌等比缩放；飞牌张数与本次出牌一一对应（原先 Web 最多 6 张、其它平台 8 张），
落点按出牌区的叠放间距排开，左右两家还会在飞行中转到倾斜角，飞完整堆牌由牌桌原位接管、不跳位；
出过的牌不再提前显示——牌堆先保持排版但透明，等飞牌落定后才亮出。动画节拍与叠放规则收敛到
共用的 `PlayFlight`，牌桌层与出牌区用同一套常量，代码量 9,850 行。

## 开发

### 环境要求

- Flutter 3.47.9+（Dart 3.13.7+）
- Android SDK 37（minSdk 35 / targetSdk 37 / compileSdk 37）
- Windows 10+

### 运行

```bash
flutter pub get
flutter run
```

### 测试

```bash
flutter analyze
flutter test
```

### 构建

构建统一由 CI 完成（在 Actions 里手动触发，选中 `v*` tag 运行即按该 tag 发布），本地不要求配置完整构建链。

## 目录

```text
lib/
├── game/          牌型识别、对局引擎、AI、记牌器、回合调度、动作广播、牌谱记录、Flame 牌桌
├── models/        扑克牌、设置与牌谱模型
├── pages/         主页、牌桌、玩法、统计、牌谱、设置
│   └── game/      牌桌布局、操作区、顶栏与浮层
├── providers/     对局状态与设置状态
├── services/      日志、音频合成、存储、统计、牌谱、文件系统
├── theme/         明暗主题与按钮样式
├── utils/         常量、格式化、窗口与平台工具
└── widgets/       手牌、牌面、座位、出牌区、记牌器、浮层外壳与通用卡片
```

## 日志与导出位置

- Windows：`文档/FlutterDdz/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterDdz/logs/`
- Web：仅保留在内存，可在设置页查看
- 牌谱文本（`ddz_hand_*.txt`）：同目录下的 `exports/`，Web 端请使用复制到剪贴板

日志单文件超过 5MB 自动轮转，保留 7 天。
